### Change Brand Colors

**In `style.css`, modify the CSS variables:**

```css
:root {
  --primary-color: #000;        /* Black */
  --secondary-color: #fff;      /* White */
  --accent-color: #0066cc;      /* Blue - Change this! */
  --text-dark: #1a1a1a;
  --text-light: #666;
}
```

### Add Your Portfolio Projects

**Replace placeholder projects in portfolio section:**

```html
<div class="portfolio-item">
  <div class="portfolio-image">
    <div class="placeholder-image">
      <span>Your Project Name</span>
      <p>Your Project Category</p>
    </div>
  </div>
  <div class="portfolio-info">
    <h3>Project Title</h3>
    <p>Project description...</p>
    <span class="portfolio-tag">Software Used</span>
  </div>
</div>
```

### Add Project Images

Replace `.placeholder-image` divs with actual images:

```html
<img src="path/to/your/image.jpg" alt="Project Name">
```

### Update Skills

Modify the skill bars and tags to match your expertise:

```html
<div class="skill-item">
  <span class="skill-name">Your Skill</span>
  <div class="skill-bar">
    <div class="skill-progress" style="width: 85%"></div>
  </div>
</div>
```
